# Перевірка форми заявки в браузері агента (Task B, Playwright)

- **Сесія:** нова, Claude Code 2.1.296 (Agent SDK), Claude Opus 5.5, effort xhigh, тека репозиторію.
  Підключено **лише `playwright`** (`init` сесії: `mcp_servers=[{"name":"playwright","status":"connected"}]`),
  Supabase і Vercel у сесії немає. Застосунок — `npm run dev` на `http://localhost:3000`.
- **Права:** `.claude/settings.json` з deny на `browser_run_code_unsafe`, `webmcp_*`,
  `browser_file_upload`, `browser_drop`, `browser_evaluate`. У сесії 21 інструмент playwright, тих
  п'яти немає. Кожен виклик схвалювався окремо (allow-правила в цьому режимі запуску не
  спрацювали, тож запит на схвалення приходив і для інструментів з `allow`). Відхилених викликів
  не було: агент не просився ні на іншу адресу, ні до `Bash`, ні до файлів.
- **Вхід у браузері:** ніде. Профіль браузера — `--isolated`, лише в пам'яті.

## Запит

> Відкрий http://localhost:3000, заповни форму заявки тестовими даними, відправ, перевір консоль і
> мережу. Інших адрес не відкривай.

Виклики 6–8 і 10–11 агент зробив паралельно. `browser_network_request` (заголовки й тіла, зокрема
`Cookie`, якби вони були) свідомо не стоїть ні в `allow`, ні в `deny`. Запит на схвалення прийшов
тричі, і щоразу його схвалено після читання: це локальний POST із вигаданими даними, без cookie.

## Результат

- **Форма відправилась.** Server Action `POST http://localhost:3000/` → `200 OK` за 213 мс,
  `content-type: text/x-component`, відповідь `{"status":"ok"}`. Введені дані у відповіді не
  повертаються. Сторінка показала «Дякуємо! Заявку отримано.»
- **У тілі запиту** лише поля форми: `firstName`, `lastName`, `email`, `phone`, `company`, `website`,
  `budget` (`1500` для «$500–1500 / міс.»), `message`, плюс службові поля Server Action.
- **Консоль:** 4 повідомлення, 0 помилок, 0 попереджень. Це службові повідомлення режиму розробки:
  підказка про React DevTools, `[HMR] connected` і два рядки `[Fast Refresh]`. Після відправки нових
  не з'явилось.
- **Мережа:** один нестатичний запит, той самий POST. Усі запити, разом зі статичними, йшли лише на
  `http://localhost:3000`, інших адрес агент не відкривав.
